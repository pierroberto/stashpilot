Make the diff pane easy to scroll and read: focus now moves between the stash list, file list, and diff (`Tab` / `Shift+Tab`, `h` / `l`), so `j`/`k`, arrow keys, and the mouse wheel scroll the diff when it is focused. Each file is introduced by a highlighted bar with its status, path, and line counts, `[` / `]` jump between files, and the pane shows the visible line range. `Enter` opens the full diff at the selected file.
